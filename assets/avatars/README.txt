Drop her photos in this folder.
==============================

Any image file works — PNG, JPG or WebP. Square crops look best
(the avatar is a circle in the chat header and a rounded square on
the companion cards), and 512×512 is plenty.

To attach a photo to a companion:

  1. Save the file here, e.g.  assets/avatars/priya.png
  2. Open the app → Companions → the ✎ button on her card
  3. Put the path in the "Avatar image" field:  assets/avatars/priya.png
  4. Save.

If the file is missing or the path is wrong, she quietly falls back
to her emoji — nothing breaks.

Suggested names for the three built-ins:

  priya.png    Flirty & Moody      (romance.priya)
  aisha.png    Emotional Support   (care.aisha)
  riya.png     Motivator & Guide   (drive.riya)

Anyone you build or clone yourself gets the same field in her editor —
name the file whatever you like.
